# Zorbix FPS Boost V3

🧪 **TEST VERSION**

Zorbix FPS Boost V3 — тестовая версия клиентского мода для Minecraft 1.20.1 Fabric.

Главная цель V3 — сделать игру более плавной и стабильной без агрессивного изменения настроек во время игры.

## ⚡ Особенности

- Мягкая оптимизация FPS
- Стабильная работа без постоянного изменения Render Distance
- Без автоматической перезагрузки чанков
- Оптимизация графики
- Оптимизация частиц
- Оптимизация облаков
- Отключение лишних визуальных эффектов
- Профили оптимизации
- Подготовка полноценного меню настроек

## 🎛️ Профили

- SAFE
- BALANCED
- PERFORMANCE
- ULTRA LOW
- CUSTOM

## 🧪 Статус

**V3 — TEST**

Версия находится в разработке и используется для тестирования стабильности, производительности и совместимости.

Некоторые функции пока отсутствуют или могут измениться в следующих версиях.

## 🎯 Цель проекта

> Меньше нагрузки. Больше плавности. Больше контроля.

Zorbix FPS Boost V3 создаётся с упором не только на максимальный FPS, но и на стабильный frametime и комфортную игру на слабых устройствах.

## ⚠️ Важно

Это тестовая версия. Перед использованием рекомендуется сделать резервную копию мира и настроек Minecraft.
